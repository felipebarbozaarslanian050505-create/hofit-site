# hofit-site

Site estático do hofit.com.br, publicado no GitHub Pages (branch `main`, raiz; domínio no `CNAME`).

Tudo aqui é **gerado** pelo repositório do app (`hofit`): `npm run site` roda `scripts/site.ts` e escreve a página inicial, a Política de privacidade, os Termos de uso, o `404.html`, o `CNAME` e os ícones a partir de `src/data/legal.ts` e `assets/images/`. Não edite nada à mão (só este arquivo): mude no app, rode `npm run site` e publique de novo.
